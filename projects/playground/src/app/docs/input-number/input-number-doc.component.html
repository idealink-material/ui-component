Design tokens

Input Number composes a native text input with two p-button instances for the stepper controls — see the Button doc page's Theming tab for the full token list it inherits.

Attributes

<p-input-number> renders as its own host element wrapping a native <input>. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
