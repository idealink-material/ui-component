Design tokens

Multi Select composes p-chip and p-checkbox internally for the closed-control chips and panel checkboxes respectively — see their doc pages' Theming tabs for the tokens they contribute. The panel and trigger otherwise use standard Material surface/outline tokens.

Attributes

<p-multi-select> renders as its own host element. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
