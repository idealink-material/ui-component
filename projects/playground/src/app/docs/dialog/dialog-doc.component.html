Attributes

<p-dialog-container> renders as its own host element — it doesn't add a backdrop or positioning itself (that's your responsibility when used declaratively, or the CDK Dialog service's when opened programmatically). Any attribute you set on the tag that isn't a recognized input is applied directly to that host element by Angular, so it passes through without extra configuration.
