Design tokens

Tabs is a thin wrapper around Angular Material's mat-tab-group, so its colors and ink-bar styling come from Material's own tab theme tokens rather than this library's --cui-* tokens.

Attributes

<p-tabs> renders as its own host element. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
