Design tokens

Data Table composes p-input, p-table, and p-pagination, each themed independently through Angular Material system tokens — see their individual doc pages for the full token list. The toolbar and footer wrappers add only layout, no color.

Attributes

<p-data-table> renders as its own host element. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
