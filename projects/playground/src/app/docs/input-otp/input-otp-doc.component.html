Design tokens

InputOtp reads its slot border, surface, and focus colors from Angular Material system tokens. Override these custom properties on an ancestor to re-theme every slot at once.

TokenUsed for
--mat-sys-outlineSlot border color.
--cui-radius-smSlot corner radius.
--mat-sys-surfaceSlot background color.
--mat-sys-on-surfaceTyped character color.
--mat-sys-primaryFocus outline color.

Attributes

<p-input-otp> renders as its own host element. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
