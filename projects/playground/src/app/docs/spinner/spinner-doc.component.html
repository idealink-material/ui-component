Design tokens

Spinner reads its default stroke color from a single Material system token; the rest of its ring (the low-opacity track) is derived from that same token.

TokenUsed for
--mat-sys-primaryDefault stroke color (both the spinning arc and the faint background track, via color-mix). Overridden per-instance by the color input.

Attributes

<p-spinner> renders as its own host element (role="status", aria-live="polite"). Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
