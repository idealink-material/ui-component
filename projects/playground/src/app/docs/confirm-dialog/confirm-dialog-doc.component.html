Design tokens

The dialog itself is a p-dialog-container under the hood, so it inherits that component's design tokens — see the Dialog doc page's Theming tab. severity: 'error' colors the confirm button using p-button's error color.

Attributes

There's no host tag to attach attributes to — the dialog is opened imperatively via Angular CDK's Dialog service, which renders p-confirm-dialog into the overlay container rather than at your call site.
