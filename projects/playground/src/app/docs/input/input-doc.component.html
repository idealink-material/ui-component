Design tokens

Input delegates its color and typography to Angular Material's form-field theme; size is implemented by overriding --mat-form-field-container-height internally, so there's no separate custom-property API to theme directly.

Attributes

<p-input> wraps Angular Material's <mat-form-field> around a native <input>/<textarea>. Attributes you set on the tag that aren't recognized inputs are applied to the p-input host element (the wrapper), not automatically forwarded to the inner native control.
