Design tokens

Knob's arc colors are controlled through the valueColor and rangeColor inputs rather than fixed CSS custom properties — they default to Material system tokens, but accept any CSS color. The component's own stylesheet pulls one token directly:

TokenUsed for
--mat-sys-on-surfaceColor of the centered value label (when showValue is true).

Attributes

<p-knob> renders as its own host element. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
