Design tokens

Menubar's own stylesheet only lays out the trigger row; submenu panels come from Angular Material's menu theme tokens, same as the Menu component.

TokenUsed for
--mat-sys-on-surfaceTop-level trigger label/icon color.
--mat-sys-surface-containerTrigger hover background.
--cui-radius-smTrigger corner radius.

Attributes

<p-menubar> renders as its own host element (a <nav>). Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
