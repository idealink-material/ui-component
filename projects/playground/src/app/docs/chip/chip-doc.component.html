Design tokens

Chip reads its palette from Angular Material system tokens (one set per color) and shares the library's focus-ring color. Override these custom properties on an ancestor to re-theme every chip at once.

TokenUsed for
--mat-sys-primary / -secondary / -tertiary / -errorBackground (filled) and border (outlined) color per color.
--mat-sys-on-primary (and per-color equivalents)Text/icon color on filled chips.
--mat-sys-*-container / on-*-containerBackground and text color for the soft variant (default).
--mat-sys-surface-variant / -on-surface-variant / -surface-container / -on-surface / -outlineBackground, text, and border for the neutral color.
--mat-sys-primaryFocus-visible outline color.

Attributes

<p-chip> renders as its own host element. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
