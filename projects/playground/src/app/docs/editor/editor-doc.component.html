Design tokens

Editor imports Quill's own "snow" theme stylesheet for the toolbar and content surface, so its look isn't driven by this library's --mat-sys-* tokens. The wrapper itself only contributes shape:

TokenUsed for
--cui-radius-mdCorner radius of the editor's outer wrapper.

Attributes

<p-editor> renders as its own host element wrapping a Quill instance. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
