Design tokens

Skeleton reads its shimmer gradient from Angular Material surface tokens and shares the library's shape tokens. Override these custom properties on an ancestor to re-theme every skeleton at once.

TokenUsed for
--mat-sys-surface-container / -surface-container-highShimmer gradient colors.
--cui-radius-smBase corner radius (the rect variant overrides this with --cui-radius-md).

Attributes

<p-skeleton> renders as its own host element. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
