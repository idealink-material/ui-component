Design tokens

Color Picker reads its border and surface colors from Angular Material system tokens and shares the library's shape tokens. Override these custom properties on an ancestor to re-theme every color picker at once.

TokenUsed for
--mat-sys-outline-variantSwatch and inline-panel border color.
--mat-sys-surfaceInline-panel background.
--mat-sys-on-surface-variantFormatted color label text color (inline mode).
--cui-radius-smSwatch and inline-panel corner radius.

Attributes

<p-color-picker> renders as its own host element. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
