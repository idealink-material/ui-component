Design tokens

Split Button has no stylesheet of its own — it composes p-button (see its Theming tab for the full token list) and a standard Material menu for the dropdown.

Attributes

<p-split-button> renders as its own host element wrapping two p-button instances. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
