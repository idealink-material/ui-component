Overview

cuiTooltip has no stylesheet of its own — it's a thin wrapper around Angular Material's MatTooltip (via hostDirectives), so the popup's color, shape, and elevation come entirely from Material's built-in tooltip tokens (e.g. --mat-sys-inverse-surface / --mat-sys-inverse-on-surface). The directive tags the overlay with a p-tooltip CSS class as a hook for future custom styling, and fixes showDelay to 300ms and hideDelay to 0ms.

Attributes

cuiTooltip is an attribute directive, not a component — it has no host element of its own. It attaches to whichever element or component you place it on (e.g. <p-button>), so every attribute you set on that host, recognized or not, is governed entirely by that host element/component, not by the directive.
