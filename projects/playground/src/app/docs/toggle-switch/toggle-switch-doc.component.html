Design tokens

Toggle Switch has no stylesheet of its own — its track, thumb, and state colors come entirely from Angular Material's slide-toggle theme tokens.

Attributes

<p-toggle-switch> renders as its own host element wrapping <mat-slide-toggle>. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
