Design tokens

Breadcrumb text and separator icons inherit their color from Angular Material system tokens; there are no component-specific custom properties to override.

TokenUsed for
--mat-sys-on-surface-variantCrumb text and separator icon color.
--mat-sys-on-surfaceCurrent (last) crumb text color.

Attributes

<p-breadcrumb> renders as its own host element (role="navigation"). Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
