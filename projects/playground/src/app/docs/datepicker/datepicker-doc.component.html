Design tokens

TokenUsed for
--mat-sys-primary / -on-primarySelected-cell background/text in multiple-selection mode.
--mat-sys-outline-variantInline calendar border and the time input's border.
--mat-sys-surfaceTime input background.
--mat-sys-on-surface / -on-surface-variantTime input text and inline hint text.
--mat-sys-errorInline error text.
--cui-radius-sm / -mdCorner radius for the time input and inline calendar frame.

The popup calendar itself is Angular Material's own mat-datepicker, themed via Material's date-picker tokens rather than this list.

Attributes

<p-datepicker> wraps Angular Material's <mat-form-field> around a native <input>. Attributes you set on the tag that aren't recognized inputs are applied to the p-datepicker host element (the wrapper), not automatically forwarded to the inner native control.
