Design tokens

Radio Group has no stylesheet of its own beyond layout — colors and state styling come entirely from Angular Material's radio button theme tokens.

Attributes

<p-radio-group> renders as its own host element wrapping a <mat-radio-group>. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
