Design tokens

Accordion and Accordion Panel have no stylesheet of their own — panel background, header, and expand-icon styling all come from Angular Material's expansion-panel theme tokens.

Attributes

<p-accordion> and <p-accordion-panel> each render as their own host element. Any attribute you set on either tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
