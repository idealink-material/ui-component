Custom templates give full control over row markup — see the code sample above for the pattern.

Design tokens

Virtual Scroller only provides the scrolling viewport — every visual aspect of each row comes from your own itemTemplate, so there are no component-specific tokens to theme.

Attributes

<p-virtual-scroller> renders as its own host element wrapping CDK's cdk-virtual-scroll-viewport. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
