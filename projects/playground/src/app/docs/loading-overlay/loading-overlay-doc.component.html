Design tokens

Loading Overlay reads its backdrop and label color from Angular Material system tokens. Override these custom properties on an ancestor to re-theme the overlay.

TokenUsed for
--mat-sys-surfaceBlurred backdrop color (mixed 80% with transparent).
--mat-sys-on-surface-variantLabel text color.

Attributes

<p-loading-overlay> renders as its own host element. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
