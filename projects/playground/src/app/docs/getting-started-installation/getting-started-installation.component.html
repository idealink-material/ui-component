Installation

Packages publish to GitHub Packages (not the public npm registry) under the @idealink-material scope.

1. Configure the registry

Add an .npmrc to your project with a GitHub PAT that has the read:packages scope: 

@idealink-material:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=<a GitHub PAT with read:packages scope>

2. Install the packages you need

npm install @idealink-material/ui-core @idealink-material/ui-utils @idealink-material/ui-icons @idealink-material/ui-theme

Check each library's peerDependencies — all currently require @angular/common/@angular/core ^22.0.0; ui-core additionally requires @angular/animations and @angular/cdk.

3. Working in this repo

Inside this workspace, install deps with npm install, then build every library once (required before ng serve playground can resolve @idealink-material/* imports): 

npm run build:libs
npm run dev

npm run dev builds all libraries once, then rebuilds them in watch mode in dependency order and serves the playground at http://localhost:4200/.
