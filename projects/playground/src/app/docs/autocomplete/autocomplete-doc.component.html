Design tokens

Autocomplete reads its border, surface, and focus colors from Angular Material system tokens and shares the library's shape tokens. Override these custom properties on an ancestor to re-theme every autocomplete field at once.

Token Used for
--mat-sys-outline-variant Default field border color.
--mat-sys-primary Border and outline color when the field is focused.
--mat-sys-surface Field background.
--mat-sys-on-surface Input text color.
--mat-sys-on-surface-variant Clear and dropdown icon color.
--mat-sys-surface-container-high Clear/dropdown button hover background.
--cui-radius-md Field corner radius.
--cui-radius-sm Clear/dropdown button corner radius.

Attributes

<p-auto-complete> renders as its own host element. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
