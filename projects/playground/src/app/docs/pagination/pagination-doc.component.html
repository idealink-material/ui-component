Design tokens

Pagination inherits its colors from Angular Material system tokens; there are no component-specific custom properties to override.

TokenUsed for
--mat-sys-primaryActive page indicator.
--mat-sys-on-surface-variantInactive controls and the item-range summary text.

Attributes

<p-pagination> renders as its own host element (role="navigation"). Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
