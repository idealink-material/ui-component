Design tokens

Avatar reads its default fill from Angular Material system tokens and shares the library's shape tokens. Override these custom properties on an ancestor to re-theme every avatar at once.

TokenUsed for
--mat-sys-primary-containerDefault avatar background.
--mat-sys-on-primary-containerInitials text color.
--cui-radius-mdCorner radius for the rounded shape.
--mat-sys-backgroundBorder color around the status indicator dot, creating a cutout against the page background.

Attributes

<p-avatar> renders as its own host element. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
