Design tokens

Progress reads its fill color from Angular Material system tokens (one per color) and its track/label colors from the surface tokens. Override these custom properties on an ancestor to re-theme every progress bar at once.

TokenUsed for
--mat-sys-primary / -secondary / -tertiary / -errorFill color for the corresponding color.
--mat-sys-surface-container-highTrack (background) color.
--mat-sys-on-surface-variantPercentage label text color.

Attributes

<p-progress> renders as its own host element. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
