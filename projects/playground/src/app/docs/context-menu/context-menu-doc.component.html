Design tokens

Context Menu adds no visual styling of its own — the popup it opens is a standard p-menu, themed the same way. See the Menu doc page's Theming tab.

Attributes

Applying pContextMenu doesn't add any wrapper element — the directive attaches behavior directly to whatever host element it's placed on, so all of that element's own attributes behave normally.
