Design tokens

TokenUsed for
--cui-input-group-heightGroup height, set per size; addons stretch to match.
--cui-input-group-radiusCorner radius applied to the group's first/last child only. Defaults to --cui-radius-md.
--cui-input-group-addon-backgroundAddon background. Defaults to --mat-sys-surface-container-low.
--cui-input-group-addon-border-colorAddon border color. Defaults to --mat-sys-outline-variant.
--cui-input-group-addon-colorAddon text/icon color. Defaults to --mat-sys-on-surface-variant.
--cui-input-group-addon-paddingAddon horizontal padding.
--cui-input-group-addon-min-widthAddon minimum width.
--cui-input-group-addon-font-sizeAddon text size.

Attributes

<p-input-group> and <p-input-group-addon> each render as their own host element. Any attribute you set on either tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
