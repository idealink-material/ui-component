Custom popover content here — any template you like.

Design tokens

Popover renders whatever template you give it with no styling of its own — the overlay panel's look is entirely up to your template's own styles. The examples above use --cui-card-bg and --cui-shadow-md to match this library's card styling, but that's a convention, not a requirement.

Attributes

Applying pPopover doesn't add any wrapper element — the directive attaches a click handler directly to whatever host element it's placed on, so all of that element's own attributes behave normally.
