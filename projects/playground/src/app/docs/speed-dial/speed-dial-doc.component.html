Attributes

<p-speed-dial> renders as its own host element. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration. Note the component doesn't fix itself to a screen corner — wrap it in a positioned container if you want the classic floating placement.
