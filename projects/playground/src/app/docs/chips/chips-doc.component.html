Design tokens

Chips reads its border, surface, and focus colors from Angular Material system tokens and shares the library's shape tokens. Override these custom properties on an ancestor to re-theme every chips field at once.

TokenUsed for
--mat-sys-outline-variantDefault field border color.
--mat-sys-primaryBorder and outline color when the field is focused.
--mat-sys-surfaceField background.
--mat-sys-on-surfaceToken input text color.
--cui-radius-smField corner radius.

Attributes

<p-chips> renders as its own host element. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
