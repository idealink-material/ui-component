Overview

company-ui is a component/design system published as five Angular libraries under the @idealink-material npm scope. It ships a component library, theming, icons, and shared utilities that build in dependency order into one package each.

Packages

PackageWhat it provides
@idealink-material/ui-utilsFramework-agnostic services/types with no UI — menu, breadcrumb, loading, permission, dialog, toast.
@idealink-material/ui-iconsIcon registry service, <lib-icon> component, icon type/token definitions.
@idealink-material/ui-themeTheme definitions (light, dark, banking, corporate, blue, green, purple) and ThemeService.
@idealink-material/ui-coreThe component library itself — atoms, forms, layout, navigation, overlays, feedback, data.
@idealink-material/ui-layoutPlaceholder library, not yet built out.
