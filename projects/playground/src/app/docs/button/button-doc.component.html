Design tokens

Button reads its palette from Angular Material system tokens (one set per color) and shares the library's shape/elevation tokens. Override these custom properties on an ancestor to re-theme every button at once.

TokenUsed for
--mat-sys-primary / -secondary / -tertiary / -errorBackground (filled), text/border (outlined, text, elevated) per color.
--mat-sys-on-primary (and per-color equivalents)Label/icon color on filled buttons.
--mat-sys-*-container / on-*-containerBackground and text color for the tonal variant.
--cui-radius-mdCorner radius.
--cui-shadow-sm / -md / -lgElevation for filled/elevated variants and their hover states.

Attributes

<p-button> renders as its own host element (role="button", focusable), not a wrapped native <button>. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
