Design tokens

InputMask reads its border, surface, and focus colors from Angular Material system tokens. Override these custom properties on an ancestor to re-theme the field.

TokenUsed for
--mat-sys-outlineField border color.
--cui-radius-smField corner radius.
--mat-sys-surfaceField background color.
--mat-sys-on-surfaceTyped text color.
--mat-sys-primaryFocus outline color.

Attributes

<p-input-mask> renders as its own host element. Any attribute you set on the tag that isn't a recognized input — id, data-*, aria-*, etc. — is applied directly to that host element by Angular, so it passes through without extra configuration.
